# 文字公告轉座標：第二輪方案比較

查閱日：2026-11-13。這是調查報告，不是已完成的定位管線；沒有執行指令、申請帳號、呼叫需金鑰的服務或改動 App 資料。

## 結論

**優先做「警方公告＋縣市門牌開放資料／新北路燈編號／OSM 路口拓樸」的離線對表，不要先把免費線上 geocoder 接成自動發布管線。**

八個優先縣市都找到門牌資料集，且已實讀各自的政府資料平臺詮釋資料。新北、臺北、高雄另已讀到小量原始資料或官方預覽；臺中已讀月份索引與原檔名稱。這證明有合法定位材料，**不等於公告中的設備已取得精確座標**。

新北目前尚未定位的是 427／717 個原始公告列；依既有「行政區＋地址」唯一口徑，是 377／607 個候選。門牌、路口與燈桿方法共同處理這一批，不能分別各算新增 377 點。定位成功率、其中各類地址占比及去重後淨新增量，本輪均未實測。

## 三、路口定位：可行，但須用拓樸，不是任意兩條線的平面交點

已實讀 [OSM `layer` 原始說明](https://wiki.openstreetmap.org/w/index.php?title=Key:layer&action=raw)及[版權頁](https://www.openstreetmap.org/copyright)：`layer` 描述交叉／重疊處的上下關係，不能把平面交叉或相同 `layer` 值當作道路連通證據。本段是建議演算法，不是已完成的全臺交點計算。

1. 先鎖縣市、行政區、完整街路段與巷名；只在同名候選的合理行政區內查找，保留原始文字。
2. 優先找 A、B 道路真正共用且可通行的 OSM 節點；分別檢查 `bridge`、`tunnel`、`layer`、`level` 與匝道關係。單純兩線的平面交叉不算路口。
3. 分隔島、雙向分離車道可能有多個相鄰節點。只有能證明是同一平面路口時才把它們當同一候選群，仍不宣稱是相機桿位；不同交流道分支不合併。
4. 「泰林路三段與泰林路三段 330 巷」可設為精確道路名稱配對案例；**本輪未實際算出該路口座標**。
5. 找不到、同名多處、路段缺圖、立體交叉不明、複雜匝道或多個不相連路口，一律留待人工，不選最近點、不取兩地中點。
6. 「往林口／臺北」不得直接朝地名中心算方位。仍需沿該道路局部路形及可靠目的地／里程證據選行向，不能重演熱點去回程誤判。

OSM 道路幾何的公開授權是 ODbL，與政府公告文字是不同來源。現有專案已以 ODbL 提供融合衍生資料庫；新增定位仍須記錄原 OSM 物件、版本、官方公告及顯名。單純少量 geocoding 結果是否觸發相同方式分享，應依下節的 OSMF 指引判斷，不宜概括稱所有查詢結果必定觸發或必定豁免。

### TGOS 全國門牌服務：已讀現行官方說明

- [TGOS 全國門牌／批次比對服務](https://www.tgos.tw/TGOS/Addr/Compare)。

現行門牌服務頁寫明：

| 類別 | 資格／申請 | 額度與形式 |
| --- | --- | --- |
| 一般使用 | 所有 TGOS 會員，線上申請批次服務 | 每日 10,000 筆；上傳 CSV，完成後通知下載；頁面稱約 1～2 天 |

`QueryAddr` 可回 JSON／XML，允許 EPSG:4326、3825、3826、3827、3828；有完整地址、期別、各層門牌及 X/Y。`oIsOnlyFullMatch=true` 可停用模糊比對；也有鎖縣市、區、路段、巷弄的選項。多結果最多 10 筆。模糊機制會找最近門牌或最近單雙號，**不是設備的誤差保證**。

**尚未核清的權利：**已讀公開說明沒有明白授權把比對結果永久快取、與 ODbL 點庫融合並隨 IPA 再散布。搜尋另有非官方主機上的舊版同意書摘要稱不得對外轉載／複製／流通，但未取得當前官方同意書，不能把它當現行全服務禁令。結論是「再散布權未確認，暫不導入公開資料庫」，不是「免費所以可以用」，也不是宣稱所有 TGOS 結果一律不能用。

應向內政部取得**對本用途有效的書面／公開條款**：批次產生座標可否永久保存、改作、公開下載、再轉授權及融入 ODbL 衍生資料庫。沒有執行申請或寄信。

## 五、免費 geocoder 條款、批次與台灣準確度

### Nominatim 公共站

已實讀 [OSMF Nominatim Usage Policy](https://operations.osmfoundation.org/policies/nominatim/)：

- 絕對上限 1 request/sec，計算整個應用，不是每名使用者各 1。
- 需有效識別應用的 User-Agent 或 Referer；不能使用預設程式庫身分。
- 大批次不鼓勵；少量一次性批次須單機、單執行緒。定期執行或超過一天的腳本限制 4 requests/min。
- 必須快取結果，避免重複查詢；不得 autocomplete、格網逆查或系統性抓完整 POI 清單。
- 應可依要求切換服務，不得假設公共站長期承擔正式產品流量。
- 以上只約束 OSMF 公共站；自架／第三方站有自己的服務條款，但資料授權仍需遵守。

[OSMF Geocoding 指引](https://osmfoundation.org/wiki/Licence/Community_Guidelines/Geocoding_-_Guideline)（2017-08-24 通過）區分直接命中與插值；非實質擷取的個別結果可與外部資料保存，不必一概讓外部資料變 ODbL。但用以系統性重建某區域全部或實質部分主要地物，或公開使用修改後的 OSM 資料庫，另有相同方式分享義務。這個指引**不會豁免公共站速率政策，也不能授權第三方服務商的額外限制**。

### Geoapify

- [已讀 geocoding 產品／批次與儲存說明](https://www.geoapify.com/geocoding-api/)。
- [已讀服務條款](https://www.geoapify.com/terms-and-conditions/)，2024-02-02、Version 5。
- 免費方案 3,000 credits/day；一般查詢 1 credit，批次最多 1,000 地址／請求，頁面列 0.5 credit／地址。需註冊自己的 API key；本輪沒有申請或查地址。
- 產品頁明寫可自行保存 address/location data，沒有額外儲存費用；條款要求 OSM 署名，免費方案另須 Geoapify 署名，其他 API 可能另有署名。
- 免費商業正式使用在條款中仍有「with some limitations」及聯絡確認要求。可儲存不等於可把所有混合資料來源一律改授權；再散布須保留回傳來源、履行各來源授權，尚未取得對本融合點庫用途的個別確認。
- 來源含 OSM、OpenAddresses、Who's on First、GeoNames 等，有 `confidence_*`；**沒有本輪台灣公告地址的命中率或公尺級準確度實測**。

### OpenCage

- [已讀條款](https://opencagedata.com/terms)及 [FAQ](https://opencagedata.com/faq)。
- 免費為測試方案：2,500 requests/day、1 request/sec；FAQ 明寫 **「Please do NOT run production services on a free trial」**，不能用多帳號規避。
- API 每次一個位置，另有上傳試算表／一次性付費方案；不是公共免費批次點庫服務。
- 使用者須守回傳資料授權，尤其 ODbL；FAQ 表示無須額外署名 OpenCage，仍須依資料來源署名。
- FAQ 明寫結果可永久保存，停止成為付費客戶後也不必刪除；可保存與再散布的來源授權仍須分別遵守，不能一律改授權。
- 上傳檔免費帳號保留 3 天、付費帳號 30 天，是 OpenCage 伺服器的檔案保存期限，不是使用者結果快取期限；支援 CSV、ODS、TSV、TXT、XLS、XLSX，免費試傳最多 100 列。
- 因免費試用不可用於正式服務，仍不是本案免費正式管線首選。

### 準確度判斷

本輪沒有對任何線上 geocoder 做台灣測試集查詢，不能提供成功率。OSM 服務與其商業包裝都可能回「道路中心、行政區中心、插值或相鄰門牌」；高信心分數不一定是完整門牌命中，更不證明有執法設備。

正式驗證至少要保存輸入、完整回傳地址、結果層級、座標來源／版本、多候選與人工判定。完全相同的縣市、區、路段、巷弄、號仍應回看道路；缺號就留待核，不以近鄰補值。宜先以官方公告中可獨立核實的門牌／路口做小型驗證集，再談命中比例。

## 七、建議的發布閘門

1. 公告本身先核機關、執法類型、現行性、明確地址及條件；定位庫只解決位置，不補造設備存在與速限。
2. 分開記錄 `公告原文 → 正規化地址 → 定位依據 → 座標系統／轉換 → 複核結果`；未命中與衝突明列原因。
3. 完整門牌、唯一同層路口、唯一桿號、官方單一里程分開標示定位品質；沒有驗證不要宣稱公尺誤差上限。
4. 保留「前／對面／附近」、快慢車道、高架／平面及取締方向；不擅自沿路平移、不猜地名方位。
5. 依現有官方優先、距離及行向規則全庫去重，再報淨新增；噪音、公告熱點與固定測速分型。沒有全部通過的列不發布。
