# 確定執法資料與定位材料：第二輪調查

查閱日：2026-11-13。已先讀 `CLAUDE.md`「資料來源」、`docs\data_sources_survey.md`、`data-pipeline\README.md`，並讀必要的 `snapshots`／`manual` 檔案。本輪沒有執行指令、改 App、匯入點位、申請金鑰或存取商業私有測速點庫；正式產出僅在 `build\survey2\`。

## 結論與建議順序

**最大槓桿是用有再利用授權的官方門牌、路燈及唯一道路路口，定位「已經有官方執法公告」的文字列；不是從地理編碼、警52或事故熱點猜設備。**八個優先縣市均找到門牌資料集，新北另有可對編號的路燈座標；但指定三個示例地址／路口／燈桿尚未實際定位成功。

直接可處理的新來源以**高雄最新固定／科技機讀表、臺北科技 135957、彰化固定聲音及地方移動公告**最有實作價值。它們有明確官方依據，但與既有 2,809 點的**淨差異仍未核定**。三個實測漏點也沒有取得新的官方設備桿位／功能定案證據；銀河點已在人工補點檔，不能重算新增。

### 最值得先做的五項

「預估」只報有來源依據的候選上界；沒有完成定位及全庫去重時，**淨新增未知**，不編造成功率、工時或數百支保證。

| --- | --- | --- | --- | --- |
| 1. 新北公告＋官方門牌／燈桿／唯一路口 | **377 個唯一待定位候選；淨新增未知**。依 607 唯一公告地址減掉已可定位 230；這是待查量，不是成功定位預估，也不是再加 427 支固定桿 | 精確門牌／唯一桿號／同層路口有可核定位依據，但「前／對面」不是精確桿位；仍須核道路與行向 | 低至中：政府 1.0／新北網站可再授權；OSM 幾何另依 ODbL。不能套地名猜方向 | 中；先處理欄位、全形字及 CRS；人工只審未命中、歧義、道路側及方向，不為湊數取中心 |

## 二、文字地址合法轉座標

### 2.1 八地門牌已找到，但不是設備座標

已實讀以下 metadata／地方原頁：新北 **168887**、臺北 **155472**、高雄 **177859**、彰化 **170727**、臺南 **120044**、新竹市 **157547**、桃園 **157689**、臺中 **177460**。均列免費及政府資料開放授權 1.0；各自網址、版本、格式、大小未知處、樣本欄位詳定位報告。

重要發現：

- **新北**平臺 1,995,627 列，分欄地址＋`x_3826/y_3826`，可離線精確對「行政區＋路名＋段＋巷弄＋號」。正式欄名 `street、road、section` 是一欄，不能錯拆。
- **臺北**原檔 118.92 MB，官方 API `count=1,158,179`，11 月 2 日匯入；91 號及 91 號二樓樣本共用座標，不能當唯一門牌數。CRS 尚待官方核定。
- **高雄**地方平臺已到 **115 年 11 月**，中央 metadata 還停在 6 月；不能固定抓第一個歷史附件。11 月樣本是投影值，題名 TWD97、資源尾端卻寫 WGS84，正式使用前須核座標系統。
- **臺南／新竹市／桃園**有人工參照點位或套圖誤差警告。門牌查中不代表設備已精確定位。
- **臺中**官方索引的十列是十個月份，不是十個門牌；10 月原檔有 TWD97／WGS84 雙重座標，但本輪未下載全檔。

新北[路燈 123962](https://data.ntpc.gov.tw/datasets/39149fe0-85ab-4e6c-99e5-60657d44895f)有 **281,011 平臺列**、29 區、週更、G1，原生欄位 `town,seqno,address,x,y,longitude,latitude` 等；`seqno` 是桿號，經緯度明列 EPSG:4326。本輪讀到八里 390001／390002 小樣本，**尚未查中 431279**。

### 2.2 路口先看官方座標，再用道路拓樸；不能以平面線交叉當路口

除 OSM 外，本輪另核到兩種政府路口定位材料，均 G1、免費：

| 來源 | 已開的原文／原檔與欄位 | 數量／版本與限制 |
| --- | --- | --- |
| 臺北 [121890 號誌位置 metadata](https://data.gov.tw/api/v2/rest/dataset/121890)／[官方 API 樣本](https://data.taipei/api/v1/dataset/9da220ce-f5a9-40a8-aacc-dc17978f3a87?scope=resourceAquire&limit=2) | 流水號、地點、行政區、WGS 經緯度；老泉街／防汛道路樣本 `121.55754,24.976234` | API `count=2,710`、匯入 2025-07-15；metadata 2026-10-13。**API 把 TSV 整行包在單一欄內**，須再依 tab 解析，不直接相信登錄表頭；不是 2,710 個相機 |
| 彰化 [37695 metadata](https://data.gov.tw/api/v2/rest/dataset/37695)／[CSV](https://email.chcg.gov.tw/df/zw3diqdbhynvsgpla8kxx7gzpjbq8n) | 編號、路口名稱、號誌種類、權責單位、緯度、經度、地區 | 年更、BIG5，metadata 2026-04-16；原檔可達但中文亂碼。coverage 起 2024、迄 2022 自相矛盾；resourceAmount=1,000 未重算，不當總數。號誌含閃光／三色，不是警52 |
| 新竹市 [67783 metadata](https://data.gov.tw/api/v2/rest/dataset/67783) | 號誌箱地點、啟用時段、更新日期；CSV／XLS／XML／JSON | metadata 2025-06-30，**沒有登錄經緯度欄**；不能只見「號誌化路口」題名就稱可直接定位 |

OSM 道路則應找**同層、可通行、真正共用節點**；檢查 `bridge/tunnel/layer/level`、分隔島與匝道。同名路、多個不相連路口、立體交叉或「往某地」有歧義就留待人工。路口中心可作公告路口的定位依據，**不能冒充設備位於某角落的精確座標**。

三個新北範例「淡金路一段 547 號」「泰林路三段／330 巷」「新市二路三段燈桿 431279」，本輪都只核到適用材料，沒有產生可發布座標。

## 三、地方警方公告：本輪真正新增的發現

22 縣市的五種類型、實際 URL、格式、欄位、日期、授權及受阻情形均整理在 `county_announcements.md`。幾個值得特別注意的版本與功能問題：

### 臺北：固定表確有比 130111 更新的官方附件

[固定／區間原頁](https://td.police.gov.taipei/cp.aspx?n=933486F3A3C42C57&s=76F2F2844D29A710)更新 **2026-09-09**，比機讀表匯入的 2026-03-10 新；[移動原頁](https://td.police.gov.taipei/cp.aspx?n=B9ECC8F49C36FDEC)為 **1151110**。兩份 PDF 已開，但工具只回 PDF 原始碼，**尚不能判斷新增幾支，更不能說新版已補至善或國安局**。警方[網站宣告](https://td.police.gov.taipei/cp.aspx?n=663DF4636E6DE905)已核為政府 1.0，不是權利不明而完全不能用的資料。

[135957 科技 JSON](https://data.taipei/api/v1/dataset/4715904f-6ce1-41c2-8a68-3bc5303f3607?scope=resourceAquire&limit=15&offset=0)則 **95 列已全部分頁實讀**：

- 1～74 為路口多功能執法，不能把紅燈／行人／轉彎／標誌線一律叫測速。
- 75～90 共 **16 列純違規停車**，依現規格不成為核心提醒目標；保留地圖／詳細資訊的規則不變。
- 91 松山高中公車站區有違停＋闖紅燈，是混合項目，不應因含停車就整列消音。
- 92 自強、93 辛亥為已知區間／跨雙白線，不重複造固定測速及區間終點。
- 94 市民高架近臺北車站、95 建國高架市民上方為非測速科技。
- 有行政區明顯錯置：臺北轉運站列為南港、南港車站列為大同；應核地址與座標，不能盲信全部欄位。

因此 **77 是提醒候選列上界，不是 77 個確定缺漏，更不是 77 支新測速**。這份科技表沒有列三個漏點所指地名，也不構成最新固定 PDF 沒有該設備的證明。

### 高雄：直接讀最新資源，不依中央題名或第一附件選版

[176549](https://data.gov.tw/api/v2/rest/dataset/176549)、[176561](https://data.gov.tw/api/v2/rest/dataset/176561)的 metadata 題名／說明仍可能停在較早批次，但 resources 已列第 4 次。本輪實開：

- [固定 JSON](https://openapi.kcg.gov.tw/Api/Service/Get/c5e78ac2-b06d-472f-9eb1-0f1df2b891cf)：內容寫 **115/10/21 更新**，官方設備編號到 **266**；前面兩個非設備物件、後面十五個空物件，API 末 Seq 為 283。首尾已核，中間未逐列重算測速功能子集，不能把物件總數直接當設備數。
- [路口科技 JSON](https://openapi.kcg.gov.tw/Api/Service/Get/406808f2-42a1-49c2-90f1-bca21920a863)：標號到 **98 行向列**，不是舊版 91。中山四路／平和東路列明超速功能但未給速限，另有行人道及轉向條件，不能全套測速嗶聲。

例明誠一路 280 號前 `22.6596,120.325981`、東向西、50，功能為超速，是「有官方可核位置／行向／速限」的資料；**是否已由 7320 或 OSM 收入尚未比對，不能稱確定新點**。

### 地方移動清單：確有官方全文，不是全靠 717 列新北公告

[雲林斗六 115 年 26 列](https://ylhpb.yunlin.gov.tw/Douliu/News_Content.aspx?n=31362&s=577863)及[臺南新化 115 年表](https://www.tnpd.gov.tw/News/Details/bafad69b-e148-8f52-9ef9-3d6a071be410/4/73183)本輪皆讀到全文。斗六另已核[自己的開放宣告](https://ylhpb.yunlin.gov.tw/Douliu/cp.aspx?n=31410)，有可再授權條款；新化授權仍未核。斗南／西螺偏長路段、部分表有快慢車道及重複排班，不能當每列一個固定點。

臺中有 **11510** 五份新 PDF，花蓮有 **11503** 新 PDF／科技圖，基隆有題名 77 固定／45 移動，彰化有九個分局／單位附件；這些是值得讀的實際公告入口，**本輪未解析附件，沒有拿題名或附件數冒充點數**。

## 六、警52、Mapillary、OSM 及政府標誌資料

### 6.1 法規不是「所有點必有可下載的完整網頁」

同條的測速警示距離一般道路100～300m、高速／快速300～1,000m，是設置警示規定，**不是由一面牌沿路倒推某個固定距離就能得到相機坐標**。同一路段多設備、雙向、長公告路段、移動執法、撤移設備都會造成歧義。

### 6.3 OSM 的 traffic_sign

已讀[OSM原始標記說明](https://wiki.openstreetmap.org/w/index.php?title=Key:traffic_sign&action=raw)。node可在道路或路旁，way標註可能表示適用路段，不代表牌柱位置；路上 `forward/backward` 相對way方向，路旁 `direction` 是牌面朝向，不可一律當車行向。

國家前綴可接國家標誌編號，但本輪**未核台灣警52實際採用tag及數量**，不自創 `TW:警52` 後當既有標註。沒有執行PBF／Overpass查詢或統計，台灣覆蓋率未知。幾何／資料仍依ODbL保存來源與署名。
